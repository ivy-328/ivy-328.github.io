# NJU Purple v1.2 — Work / Practice Cleanup

这版只修你指出的结构问题，不重新换视觉风格。

## 修正内容

1. **首页**
   - 移除误放在首页的「作品 / WORK → 精选新闻作品」大区块。
   - 也移除“社会实践已经移至田野与实践”这种开发说明式文案；这种话不应该出现在成品网站里。

2. **Work / 作品**
   - 只保留有封面的作品。
   - v1.1 中最后 3 个没有封面的作品不会再显示。
   - 桌面端改成两列、最大约 520px 的卡片，不再让一个可点击框横向占满整个画幅。
   - 图片比例固定为 16:9，卡片更像网页作品集，不像巨型按钮。

3. **Fieldwork & Practice / 田野与实践**
   - 把“上面的经历”和“下面另加的链接卡”合并回同一个经历卡。
   - **新华日报 / 交汇点**：照片就是这段实践的封面；相关报道只作为卡片内部的小按钮。
   - **县级融媒体**：照片就是这段实践的封面，不再单独生成一个重复的链接框。
   - 盱眙龙虾、亳州支教、青年在“县”场、社区服务放在下方较小的补充卡片里。
   - 脚本会优先从你现有 v1.1 数据里自动寻找新华日报和县级融媒体的图片，因此不用重新上传照片。

## 使用方法

把这个压缩包内的所有内容复制到：

```text
D:\git_projects\ivy-328.github.io
```

覆盖/合并文件夹即可。

然后 Git Bash：

```bash
cd /d/git_projects/ivy-328.github.io
ruby apply_v12_cleanup.rb
bundle exec jekyll serve
```

浏览器重点看：

```text
http://127.0.0.1:4000/
http://127.0.0.1:4000/zh/
http://127.0.0.1:4000/work/
http://127.0.0.1:4000/zh/work/
http://127.0.0.1:4000/practice/
http://127.0.0.1:4000/zh/practice/
```

如果还是旧样式：

```text
Ctrl + F5
```

## 安全机制

脚本运行前会把它修改到的原文件自动备份到：

```text
_backup_nju_v12_时间/
```

如果脚本没有自动识别到“新华日报封面”或“县级融媒体封面”，终端会明确打印 `⚠ 未自动识别`。这时不要 push，把终端输出和 Practice 截图发回来即可。

## 仍然不要 `git add .`

你的本地 Gemfile 之前为了 Windows/Jekyll 运行做过单独修改。确认页面满意以后，只提交这次实际变化的页面、数据和 CSS 文件。
